# Тестовое задание

**Срок:** 3 дня. **Бэкенд на Yii2 (PHP 7.4+).** Всё решение должно быть оформлено как
отдельный модуль Yii2 (например, `attention-monitor`).

## Что нужно сделать

Прототип системы, которая через веб-камеру следит за учеником во время урока,
фиксирует его вовлечённость и после урока показывает учителю отчёт.

## Как это работает

Ученик садится перед камерой. Система каждую секунду оценивает, что он делает, и
относит к одному из трёх состояний:

- **Вовлечён** — ученик в кадре, лицо обращено к экрану. Если ученик смотрит вниз в
  тетрадь — это тоже считается «вовлечён».
- **Отвлечён** — ученик в кадре, но смотрит в сторону (на соседа, в окно).
- **Отсутствует** — ученика нет в кадре дольше двух секунд.

Все наблюдения копятся на сервере. По окончании урока (или прямо во время) можно
открыть страницу отчёта по этой сессии.

**Важно:** видео и изображения с камеры не уходят на сервер. Сохраняются только метки
состояний и время.

## Что должно быть в отчёте  

- ID ученика, ID сессии, время начала, время окончания, общая длительность.
- Сколько времени ученик был «вовлечён», «отвлечён», «отсутствует» — в минутах и в
  процентах.
- Сколько раз отвлекался, сколько раз выходил из кадра.
- Самый длинный непрерывный эпизод отсутствия — длительность и в какой момент
  урока случился.
- Самый длинный непрерывный эпизод вовлечённости.
- Общий показатель вовлечённости за урок — одно число от 0 до 100.
- **Таймлайн урока** — цветная горизонтальная полоса со шкалой времени: зелёные
  участки = «вовлечён», жёлтые = «отвлечён», серые = «отсутствует».
- **График вовлечённости по окончании сессии** — обязательно отобразить динамику
  вовлечённости по минутам урока (линейный/столбчатый график), чтобы учитель
  видел, как менялся уровень внимания ученика на протяжении занятия.

## Технические требования к модулю

- Модуль Yii2 (рабочее название — `attention-monitor`) с собственными
  контроллерами, моделями, миграциями, views и ассетами.
- Подключение в `config/web.php`:

```php
'modules' => [
    'attention-monitor' => [
        'class' => 'app\modules\attentionMonitor\Module',
    ],
],
```

## Устойчивость к сбоям

Система не должна падать, если: нет доступа к камере, разорвалась связь во время
сессии, на сервер пришли пустые или битые данные, запрошен отчёт по
несуществующей сессии.
